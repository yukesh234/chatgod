# 🚀 Chatbot — Playful & Powerful

**Overview**
- **What:** A friendly full-stack chatbot project with a lightweight Node backend and a Vite + React frontend.
- **Why:** Fast local dev, easy customization, and built to be a great starting point for chat UI experiments.

**Highlights**
- **Sleek UI:** Minimal React + Vite frontend for instant feedback.
- **Simple Server:** Tiny Node.js backend to handle API requests.
- **Easy to Run:** Clear commands below to get both parts running.

**Quick Start**
- **Backend:**

```powershell
cd backend
npm install
npm start
```

- **Frontend (dev):**

```powershell
cd frontend\\chatbot
npm install
npm run dev
```

Open the frontend URL shown by Vite (usually http://localhost:5173) and enjoy your chatbot.

**Project Structure**
- **Backend:** lightweight server in the `backend` folder (entry: `index.js`).
- **Frontend:** React + Vite app in `frontend/chatbot` (entry: `src/main.jsx`).

**Development Tips**
- **Env:** Check `backend/.env` (if present) and `frontend/chatbot/.env` for API keys and ports.
- **Hot reload:** Vite and Node's nodemon (if configured) provide fast feedback.
- **Logs:** Watch the backend terminal for API requests; the frontend hot-reloads on save.
